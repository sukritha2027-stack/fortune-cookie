# Piece template

Every content piece is one markdown file in `content/day-N/`, named `NN-<channel>-<type>.md` in posting order.

```markdown
# <NN> · <Channel> · <Type>

**Status:** DRAFT | READY | NEEDS FOUNDER
**Day / date:** Day N · <weekday, date>
**ICP:** Story-Poster | Quiet Overthinker | Manifester
**Goal:** <the one action we want>
**Founder time:** <minutes>
**Link:** https://www.fortunecookie.fit/?ref=<channel>-day<N>

## Angle
<the chosen angle from brainstorm.md, one line, and why>

## Final copy
<exactly what gets posted or sent: caption, message, post body. Two variants of the hook/first line, marked A and B.>

## Visual / video
<for images: what it is, file name in this folder or "use the app's share card (Story format)", generation prompt if any>
<for video: shot list>
| Time | Shot | On-screen text | Audio |
|---|---|---|---|
| 0–3 s | ... | ... | ... |

**Cover frame:** ...

## Founder steps
1. <action> (<min>)
2. ...

## Sources
- <every external fact, rule or handle used, as [title](url)>
```

`brainstorm.md`, `audit.md` and `index.md` sit beside the pieces in the same folder.
